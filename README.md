# 낙성 탐구 설계실

IB PYP 탐구단원(UOI)을 처음 설계하는 선생님을 위한 웹 앱입니다.
낙성초등학교의 엑셀 UOI 플래너를 바탕으로, 2025 PYP 개편 내용과 2022 개정 교육과정 성취기준, 우리 학교 교육과정을 함께 담았습니다.

설치할 것이 없습니다. 브라우저(크롬·엣지·웨일)에서 주소를 열면 바로 씁니다.

---

## 무엇을 할 수 있나요?

| 기능 | 설명 |
|---|---|
| **탐구 프로그램(POI) 계획표** | 1~6학년 × 초학문적 주제 6개를 한 장에서 보고, 개념·학습자상·ATL·성취기준이 고르게 배치되었는지 확인 |
| **새 단원 시작 + 추천 예시** | 학년과 주제를 고르면 맞는 **추천 예시 1개**가 나오고, 예시에서 시작하면 초안이 만들어짐 (36칸, 42개 예시) |
| **담임 주도안** | 교과전담 과목(지금은 과학·체육)이 중심인 칸에는 담임 교과 중심의 대안을 먼저 보여 줌. 전담 과목은 `school.js`의 `specialists`로 바꿈 |
| **5단계 설계 + 운영 기록** | 개요 → 개념·탐구 → 교과·성취기준 → 평가 → 차시 운영까지가 설계. 실천·성찰은 운영하면서 채움(필수 아님) |
| **LOI마다 작은 탐구 순환** | 차시표가 LOI별로 묶여 조사 → 정리 → 공유·일반화가 한 바퀴 도는지 보여 줌. 붙임쪽지·큰 종이 생각 루틴 14가지 제공 |
| **단원 길이 20~30차시** | 새 단원 기본 24차시. 20차시 미만이면 알려 줌 (국내 IB 학교 운영 사례 기준) |
| **안내 모드** | 처음 쓰는 선생님용. 필수 칸과 할 일 안내만 보이고 심화 칸은 접혀 있음 |
| **설계 점검** | 오른쪽 ‘꼭 할 일’ 목록이 빠진 것을 알려 줌 (예시 문장을 그대로 두면 알려 줌) |
| **성취기준 고르기** | 2022 개정 성취기준 612개 중 우리 학년 연간지도계획에 있는 것부터 골라 넣기, A·B·C 성취수준으로 루브릭 만들기 |
| **내 AI에 물어보기** | 단계마다 ‘AI 도움 ▾’ → 프롬프트를 복사해 ChatGPT·제미나이·클로드 등에 붙여 넣고, 받은 답을 다시 칸에 넣기 |
| **인쇄·결재용 보기** | 결재란이 있는 A4 단원 계획서로 정리해 인쇄 |
| **엑셀 내보내기** | 원래 엑셀 플래너와 같은 양식으로 내려받기 |
| **자료실** | 우리 학교 / 추천 주제 지도 / IB PYP 기본 틀 / 용어 사전 / AI 프롬프트 / 성취기준 자료 |
| **학교 공동 저장소**(선택) | 파이어베이스를 연결하면 여러 선생님이 같은 POI를 실시간으로 함께 설계 |

## 저장 방식은 두 가지입니다

| | 설정 | 저장되는 곳 | 함께 보기 |
|---|---|---|---|
| **① 기본** | 그냥 올리면 이 방식 | 각 선생님의 브라우저 | 단원 파일을 주고받아야 함 |
| **② 학교 공동 저장소** | `firebase-config.js` 작성 | 파이어베이스(학교 계정) | **실시간으로 함께 보고 고침** |

②를 켜는 방법은 아래 「파이어베이스 연결하기」에 있습니다. 먼저 ①로 써 보고 나중에 ②로 옮겨도 됩니다.

## ① 기본: 데이터는 **내 브라우저에만** 저장됩니다

이 앱은 서버가 없습니다. 작성한 내용은 **지금 쓰는 컴퓨터의 브라우저**에 저장됩니다.

- 다른 컴퓨터나 다른 브라우저에서는 보이지 않습니다.
- 브라우저의 ‘인터넷 사용 기록 삭제(쿠키·사이트 데이터)’를 하면 지워질 수 있습니다.
- 그래서 왼쪽 아래 **💾 백업 파일로 저장**을 자주 눌러 주세요. 7일이 지나면 앱이 알려 줍니다.

### 선생님끼리 단원을 나누는 방법
1. 단원 화면 오른쪽 위 **더보기 ▾ → 단원 파일로 저장** (파일 이름: `3학년_단원제목.uoi.json`)
2. 메신저·메일로 파일을 보냄
3. 받은 선생님은 왼쪽 아래 **📂 백업·단원 파일 불러오기**
   - 같은 단원이 이미 있으면 덮어쓰지 않고 ‘(가져옴)’ 복사본으로 들어옵니다.

## GitHub Pages로 올리는 방법 (설치 없이 웹에서)

1. [github.com](https://github.com)에 로그인합니다. (계정이 없으면 가입)
2. 오른쪽 위 **＋ → New repository**
   - Repository name: 예) `nakseong-ib`
   - **Public** 선택 (무료 GitHub Pages는 공개 저장소에서 동작)
   - **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더 안의 **모든 파일**을 끌어다 놓습니다. (`index.html`, `*.js`, `README.md`, `.nojekyll`)
   - 폴더째가 아니라 **파일들**을 올려야 합니다.
   - `.nojekyll`은 숨김 파일이라 안 보이면 없어도 동작합니다.
5. 아래 **Commit changes** 버튼
6. 저장소 위쪽 **Settings → 왼쪽 Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
7. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다.
   예) `https://아이디.github.io/nakseong-ib/`
8. 이 주소를 선생님들께 나누면 됩니다.

### 고친 내용을 다시 올릴 때
저장소 화면 → **Add file → Upload files** → 바뀐 파일만 끌어다 놓고 **Commit changes**. 1~2분 뒤 반영됩니다.
선생님들이 저장한 단원 데이터는 각자의 브라우저(또는 파이어베이스)에 있으므로, 앱을 새로 올려도 지워지지 않습니다.

## ② 파이어베이스(학교 공동 저장소) 연결하기

한 번만 설정하면 **여러 선생님이 같은 POI를 실시간으로 함께** 만듭니다. 한 사람이 고치면 다른 선생님 화면에 바로 반영되고, 인터넷이 끊겨도 각자 브라우저에 계속 저장됩니다. 무료 요금제(Spark)로 충분합니다.

### 1단계 — 프로젝트 만들기
1. [console.firebase.google.com](https://console.firebase.google.com) 접속 (학교 구글 계정 권장)
2. **프로젝트 추가** → 이름 예) `nakseong-ib` → Gemini와 Google 애널리틱스는 **사용 안 함** → 만들기

### 2단계 — 구글 로그인 켜기
3. 왼쪽 **보안 > Authentication** → **시작하기**
4. **Google** 선택 → 사용 설정 → **공개용 이름**을 알아보기 쉽게(예: `낙성 IB 탐구 설계실`) → 지원 이메일 선택 → 저장
   - 공개용 이름은 선생님들이 로그인할 때 보는 이름입니다.

### 3단계 — 데이터베이스 만들기
5. 왼쪽 **데이터베이스 및 스토리지 > Firestore Database** → **데이터베이스 만들기**
6. **Standard 버전**, ID는 `(default)`, 위치는 **asia-northeast3 (서울)**, 모드는 **프로덕션 모드**
   - 위치는 나중에 바꿀 수 없습니다. 예약된 백업은 유료이므로 건너뜁니다.
7. **규칙(Rules)** 탭 → 이 폴더의 `firestore.rules` 내용을 붙여 넣고, `teachers()` 목록을 **우리 학교 선생님들의 구글 이메일**로 바꾼 뒤 **게시**
   - 여기 적힌 계정만 읽고 쓸 수 있습니다. 새 선생님이 오면 이메일을 추가하고 다시 게시하세요.

### 4단계 — 앱에 설정 값 넣기
8. 콘솔 왼쪽 **⚙ 설정 > 일반** → 아래 **내 앱** → **웹(</>)** 아이콘 → 앱 닉네임 입력 → 등록 (호스팅 체크 안 함)
9. 나오는 `firebaseConfig` 값을 `firebase-config.js`의 같은 이름 칸에 옮겨 적고, **`enabled: true`** 로 바꿉니다.
10. 바뀐 `firebase-config.js`를 깃허브에 다시 올립니다.

### 5단계 — 주소 승인
11. 콘솔 **Authentication > Settings > 승인된 도메인**에 깃허브 주소의 도메인 **`아이디.github.io`** 를 추가합니다. (없으면 로그인 창이 열리지 않습니다)

### 다 되면
- 앱 왼쪽 아래가 **“구글 로그인이 필요합니다”** → 로그인하면 **“학교 공유 저장 중”** 으로 바뀝니다.
- 이미 혼자 만들어 둔 단원이 있으면 **“⬆ 아직 공유되지 않은 단원 N개 올리기”** 가 뜹니다. 눌러야 올라갑니다(누르기 전에는 나만 봅니다).
- 단원 제목 옆에 **마지막으로 고친 선생님**이 표시됩니다.
- **예시 단원은 공유되지 않습니다.** 내 브라우저에만 남습니다.

### 알아 둘 점
- `firebase-config.js`의 `apiKey`는 **웹앱에서 원래 공개되는 값**입니다. 보안은 3단계의 **규칙**과 5단계의 **승인된 도메인**이 담당합니다. 규칙을 반드시 넣어 주세요. (규칙 없이 테스트 모드로 두면 누구나 볼 수 있습니다)
- `firestore.rules`에 **실제 이메일을 적은 채로 공개 저장소에 올리지 마세요.** 이메일은 콘솔에서만 채우면 됩니다.
- 학생 이름·사진 같은 개인정보는 넣지 않습니다. 단원 설계 내용만 저장합니다.
- 나중에 AI 기능을 앱 안에서 바로 쓰려면 파이어베이스 **Cloud Functions**로 중계를 만들어 `window.AI_BACKEND`에 연결하면 됩니다. (외부 호출은 유료 요금제 필요)

## 공개 전 확인할 점

- **공개 저장소**이므로 누구나 파일을 볼 수 있습니다.
  - `school.js`에는 학교 누리집에 공개된 수준의 정보(학교명·지역·교육목표·특색교육·지역 자원)만 담았습니다. 교직원 이름·연락처는 넣지 않았습니다.
  - 학생 이름 같은 개인정보는 앱에도, 프롬프트에도 넣지 마세요.
- **성취기준·성취수준 문장**(`standards.js`)은 교육부 「2022 개정 교육과정에 따른 성취수준」에서 가져왔습니다. 공개 배포 전에 원문 자료의 공공누리 이용 조건을 확인해 주세요.
- 추천 예시 36개는 **예시안**입니다. 학교 협의를 거쳐 다듬어 쓰세요.
- 파이어베이스를 연결했다면 `firestore.rules`의 **선생님 이메일은 저장소에 올리지 말고** 콘솔에서만 채우세요.

## 다른 학교에서 쓰려면

- 파이어베이스를 쓰면 그 학교 프로젝트를 새로 만들고 `firebase-config.js`의 `school` 이름을 바꿉니다.
- `school.js` 한 파일만 그 학교 내용으로 바꾸면 됩니다. (비전, 교육목표, 지역 자원, 행사, 학교자율시간)
- `standards.js`의 학년·학기 연결(`use`)은 낙성초 연간지도계획 기준입니다. 성취기준 문장 자체는 전국 공통입니다.
- `starters_a.js`, `starters_b.js`의 추천 예시에서 `local`(지역 연계)을 그 학교에 맞게 고치면 됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 스타일 |
| `data.js` | IB PYP 기준 자료, 용어 사전, 예시 단원 |
| `school.js` | 우리 학교 맥락 (학교교육계획에서 추림) |
| `standards.js` | 2022 개정 성취기준 612개 + 성취수준 A·B·C + 학년·학기 연결 |
| `starters_a.js`, `starters_b.js` | 추천 예시 36개 (1~3학년, 4~6학년) |
| `starters_c.js` | 담임 주도안 6개 (과학 중심 예시의 대안) |
| `starters.js` | 추천 예시를 새 단원 시작 창과 자료실에 보여 주는 장치 |
| `store.js` | 저장, 설계 점검, 엑셀·백업 내보내기 |
| `unit.js`, `unit2.js` | 단원 편집 화면 6단계 |
| `app.js` | POI, 탐구단원 관리, 자료실, 버튼 동작 |
| `std.js` | 성취기준 고르기, 성취수준 루브릭, 반영 현황 |
| `prompts.js`, `bridge.js` | 내 AI에 붙여 넣는 프롬프트, AI 답 붙여넣기 |
| `print.js` | 인쇄·결재용 보기 |
| `ai.js`, `chat.js` | AI 제안·AI 도우미 (claude.ai에서 열거나 AI 중계를 연결했을 때만 보임) |
| `firebase-config.js` | **학교 공동 저장소 설정 — 여기만 고치면 됩니다** |
| `firebase.js` | 파이어베이스 연결·구글 로그인·실시간 공유 |
| `firestore.rules` | 파이어베이스 콘솔에 붙여 넣는 보안 규칙 (앱 동작에는 쓰이지 않음) |
