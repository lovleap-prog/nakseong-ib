# 연수자료

Claude가 이 앱을 고치거나 단원 예시·안내 문구를 쓸 때 **먼저 읽고 참고하는** 자료 창고입니다.

## 넣는 방법

- GitHub 저장소 화면에서 이 `연수자료` 폴더로 들어가 **Add file → Upload files**로 파일을 끌어다 놓고 **Commit changes**를 누릅니다.
- 또는 Claude 대화창에 파일을 붙이고 “연수자료에 넣어 줘”라고 말합니다.

## 파일 형식

- **PDF, 글(.md·.txt), 사진(.png·.jpg)** 은 Claude가 바로 읽습니다.
- **한글(.hwp·.hwpx)** 파일은 잘 읽지 못하니 **PDF로 저장해서** 넣어 주세요.
- 파일 이름에 무엇인지 알 수 있게 적어 주세요. 예) `2025_PYP개편_연수_전남교육청.pdf`

## 주의

- 이 저장소가 GitHub Pages로 공개되어 있으면 **이 폴더의 파일도 누구나 내려받을 수 있습니다.**
  외부 공개가 안 되는 자료(학생 개인정보, 배포 금지 연수 자료)는 넣지 마세요.
